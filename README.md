# Ryan Edley — Performer & Creative

One-page, mobile-first portfolio for acting, comedy, post-production, AI and motion. Built as plain HTML, CSS and JavaScript; no package install or build step is needed.

## Edit the content

Update `content.json` for the reel ID, caption, contact email, headshot and the clearly marked media placeholders. The featured reel is unlisted and embedded only after a visitor presses Play. Keep private video IDs out of this public repository; no video visibility settings were changed.

## Publish

GitHub Pages is configured to serve the repository root from `main`. Keep `index.html`, `content.json` and `assets/` at the root of the repository.
